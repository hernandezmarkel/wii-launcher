`online.cpp` y `online.h` son copia literal del launcher de Mario Party 9 (mismo protocolo de sala,
puerto 47630, `HELLO <revisión>/<disco>`). No se editan aquí: si cambian en mp9-recomp, se vuelven a
copiar y se actualiza el hash de `texts.h`. `tests` comprueba que el launcher unificado y el original
hablan el mismo protocolo.
